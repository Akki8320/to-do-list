# Fun Daily Quests ✨ 
**Gamified Task Management & Learning Tracker**

このプロジェクトは、日々のタスク管理を「冒険（クエスト）」に変えるゲーミフィケーション・アプリです。
This is a gamified task management app that turns your daily to-dos into an "adventure."


## 🌟 Features / 主な機能
- **Gamification / ゲーミフィケーション**:
  - タスク完了や学習メモの記録でXP（経験値）を獲得。 / Earn XP by completing tasks and recording learning notes.
  - レベルに応じてペットが進化（全18段階：🥚 → 🐣 → ... → 🐲 → 👽）。 / Pets evolve as you level up (18 stages).
- **Theme Selection / テーマ切り替え**:
  - Space, Cozy, Forest, Ocean の4つの美しいテーマを搭載。 / Four beautiful themes to match your mood.
- **Learning Log / ラーニング・ログ**:
  - 「1% better every day」を掲げ、学んだことを記録する専用セクション。 / A dedicated section to record what you've learned.
- **Dynamic UI**:
  - タイトル上を恐竜が歩き、踏んだ文字が沈むインタラクティブな演出。 / Interactive dino animation that reacts to the title text.

## 🛠 Tech Stack / 使用技術
- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid), Vanilla JavaScript
- **Graphics**: SVG, Canvas Confetti (Level-up animation)
- **Utilities**: Python (Pillow) - 恐竜画像の背景透過処理や色解析に使用。 / Python was used for image processing (transparency/color analysis).

## 🚀 How to Use / 使い方
1. このリポジトリをクローンまたはダウンロードします。 / Clone or download this repository.
2. `index.html` をブラウザで開くだけで実行可能です。 / Simply open `index.html` in your browser.
3. タスクを追加してクエストを開始しましょう！ / Add your first task and start your quest!
